# 画像アセット置き場

ここに画像をアップロードしてください。フォルダごとの用途は下記の通りです。
（PNG 推奨 / 透過が必要なものは透過 PNG。サイズは仮で OK、後で調整できます）

| フォルダ | 用途 | 例 |
|---|---|---|
| `corn/` | 品種（1打鍵の見た目） | 普通コーン, キャラメル, トリュフ塩, 純金 |
| `equipment/` | 設備（自動生産） | フライパン, 焚き火, 電子レンジ, 業務用マシン, ダイソン球 など |
| `artifacts/` | 転生アーティファクト | 魔法の塩, 黄金のフライパン など |
| `ui/` | ボタン・アイコン・フレーム類 | 通貨アイコン, ボタン, パネル |
| `effects/` | 弾けるエフェクト・破裂演出 | はじけ粒, コンボ光, ターンッ！演出 |
| `background/` | 背景 | タイトル背景, ゲーム画面背景 |

## ファイル名の付け方（おすすめ）
- 半角英数・ハイフン区切り。例: `corn-caramel.png`, `equip-microwave.png`, `artifact-magic-salt.png`
- 連番が要る場合は `effect-pop-01.png` のようにゼロ埋め。

困ったら名前は何でも置いてOKです。こちらで参照を合わせます。
