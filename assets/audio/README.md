# 音声アセット置き場

音楽（BGM）と効果音（SE）をここに入れてください。

| フォルダ | 用途 | 例 |
|---|---|---|
| `bgm/` | ループする背景音楽 | タイトル, 序盤, 終盤(カオス), 転生演出 |
| `se/`  | 単発の効果音 | 打鍵「ターンッ！」, はじけ音, コンボ, 購入, 転生 |

## ファイル形式
- **おすすめ: `.mp3`**（全ブラウザ対応・軽い）。`.ogg` / `.wav` も可。
- BGM はループ前提なので、頭とお尻が自然につながる素材だと◎。
- SE は短く（0.1〜1秒程度）、音量はやや小さめが扱いやすい。

## ファイル名の付け方（おすすめ）
- 半角英数・ハイフン区切り。
  - BGM: `bgm-title.mp3`, `bgm-early.mp3`, `bgm-chaos.mp3`, `bgm-prestige.mp3`
  - SE:  `se-type.mp3`, `se-pop.mp3`, `se-combo.mp3`, `se-buy.mp3`, `se-prestige.mp3`

名前は自由でOK。こちらで参照を合わせます。
