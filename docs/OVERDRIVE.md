# Popcorn Overdrive — プレイできる第一試作

## 現在の調整（段階的な成長を優先）

この節が以下の初期試作の数値より優先される。

- 通常の打鍵粒数は1→2→3→4→5。完成語数12/35/80/160で段階的に増える。コンボだけでは描画密度を跳ね上げない。
- 単語完成の追加粒は初期2粒から成長。三段破裂はラッシュ中のみ。
- 24語完成後から熱を蓄積。正解文字+0.6、単語完成+2、毎秒-0.4。序盤数語でのラッシュを防ぐ。
- 自動生産は前版の25%、単語の基礎報酬倍率は8→4。最初の設備の描画は約3.2秒に1粒から。
- 背景・BGMは元の容器進行条件で切り替える。完成語数による制限は撤去（2026-09-17）。追加したキッチン・屋台は最初の2容器に対応し、既存BGMの境界は元のまま。
- 飛翔480／残留1200の上限はそのまま。序盤から上限を埋める演出にはしない。

## 狙い

「打った一発が気持ちいい → 設備が育つ → 次の一発がもっと気持ちいい」を循環させる。
世界を驚かせる完成版ではなく、この循環の手触りを確かめる試作。

## 変更

- 設備の基礎生産を上方修正。最初のフライパンは40粒で購入、毎秒4粒。
- 正解1文字で熱+2、単語完成で+12。100未満は毎秒3減少。満タンになる打鍵で自動ラッシュ。
- 熱で設備が最大3倍に加速。満タンで12秒のラッシュが自動発動。
- ラッシュ中は打鍵と設備が8倍。熱の再充填は終了後。追加操作は不要。
- 単語完成報酬は「かな数 × 打鍵出力 ×8 ＋ 現在の自動生産2秒分」。
- 設備10/25/50/100台で、その設備全体の生産がそれぞれ2倍（最終16倍）。
- 施設購入は購入ボタン／2キーによる手動操作のみ（2026-09-17）。既存セーブでも自動購入を無効化。購入済み施設の自動生産は継続。
- 追加した設備一覧・熱ゲージ・ラッシュボタンは撤去。元の画面と操作を維持。
- 打鍵位置から噴き出す粒、単語完成の三段破裂、設備の反動と一斉排出、床で跳ねる粒、コンボに伴い上がる打鍵音を追加。
- 得点と描画粒子数は分離。飛翔480粒＋残留1,200粒の別枠。自動生産は飛翔120粒／残留420粒までで、手入力を優先。
- 手入力は初期レベルから1打鍵6粒。着地して山に残り、45〜51秒後までに消える。自動生産は20〜26秒。最後の5秒でフェード。
- 新規生成した透明背景の4種類の通常コーンをランダムに混ぜる。画像は描画開始時に96pxテクスチャへ一度だけ縮小し、再利用する。

## 実行

Node.jsのある環境でリポジトリ直下から `node preview.cjs`。
ブラウザで http://127.0.0.1:4173 を開く。
テスト：`node --test tests/economy.test.cjs`。

操作：お題のローマ字を入力。1=レベルUP、2=次の施設、3=品種研究。
自動増設とラッシュは追加操作不要。音量は右上のボタン。

## 序盤シーンと揺れの修正

- 画面全体の衝撃移動、打鍵ごとの文字パネル拡大、ミス時の横揺れ、得点の拡大を停止。ミスは枠の色で知らせる。
- 内蔵画像生成でキッチンと屋台を追加。累計0〜499粒はキッチン、500〜3499粒は屋台、3500粒から既存の遊園地。BGMはこの間同じ曲を維持。
- 画像と最終プロンプト：`assets/web/background/generated/`。背景の元素材は保持。
- `/?preview=early` はセーブを書き換えず序盤を遊ぶ確認用URL。通常URLは従来どおり保存。
- ブラウザでキッチン→屋台の切り替えと、画面・文字・数字のtransform/animationがnoneになることを確認。

粒子検証：`node --test tests/particles.test.cjs`。着地後の残留と消滅、飛翔・残留の上限、自動生産から手入力粒を保護する動作を検証。
