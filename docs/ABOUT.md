## ◆ ゲーム紹介（ブログ本文・長い版）

**「ポップコーンタイピング」** は、ローマ字タイピングと放置（クリッカー）を合わせた、
ゆるくて中毒性のあるブラウザゲームです。

画面に出てくるお題をキーボードで打つと、そのたびにポップコーンが**ポンッ！と花火のように弾けて**増えていきます。
打って貯めたポップコーンで「**1打鍵の威力（品種・レベル）**」や「**自動で焼く施設**」を強化。
たまったポップコーンは中央の**容器（バケツ）**にどんどん溜まっていき、満タンにするとクリア！
そして――**ひとまわり大きな容器**がやってきます。

> Sカップ → Mカップ → バケツ → ダンプトラック → ビル → 山 → 街 → 日本列島 → **地球** → 太陽系 → 銀河 → **宇宙ぜんぶ** …！

進むほど背景も BGM も変化し、終盤は**宇宙**が舞台に。スケールがどんどんバカでかくなっていく様子がクセになります。

そして**基本は放置ゲー**。施設を増やしておけば、**プレイしていない間もポップコーンは焼け続けます**。
ちょっと休憩して戻ってくると「うわ、こんなに増えてる！」――その瞬間がいちばん楽しい。

宇宙まで満タンにして全クリアすると、**チートモード（生産×100）**が解放。最初から猛スピードでもう一周できます。

### 特徴
- ⌨️ **本格ローマ字タイピング**：ヘボン式／訓令式どちらでもOK（し＝shi/si）。長音「ー」も対応。
- 🍿 **打鍵が気持ちいい**：1文字ごとに弾ける花火エフェクト＋効果音。コンボでどんどん派手に。
- 🪣 **わかりやすい目的**：容器を満タンにするだけ。満タン→もっとデカい容器へ、の無限ループ。
- 😴 **放置でも進む**：施設が自動でポップコーンを生産。離れていても増える。
- 🌍 **スケールがバカでかい**：カップ→地球→宇宙へ。背景とBGMもフェーズで変化。
- 😈 **やり込み**：全クリアでチートモード（×100）解放。
- 🎵 流行語・遊園地・おやつネタのゆかいなお題がいっぱい。

### 遊び方
1. ローマ字でお題を入力 → ポップコーンが弾けて増える。
2. 画面下のボタン（またはキー **1 / 2 / 3**）で強化：
   - **1：レベルアップ**（1打鍵の威力アップ）
   - **2：施設購入**（自動生産を増やす）
   - **3：品種研究**（1打鍵の威力が一気にジャンプ）
3. 中央の**容器を満タン**に → クリアでもっと大きな容器へ！
4. 疲れたら**放置**でOK。戻ってくると増えています🍿
