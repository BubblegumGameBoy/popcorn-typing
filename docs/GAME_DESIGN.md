# ポップコーン・タイピング 企画ドラフト

> タイピング × クリッカー（放置）ゲーム。
> 「自分で打って稼ぐ気持ちよさ」と「設備で自動生産する中毒性」を両立し、
> 最終的に転生（プレステージ）でインフレを楽しむバカゲー。

ステータス: **ドラフト v0.1**
最終更新: 2026-06-15

---

## 0. コンセプト / 一行説明

> **打鍵が、爆ぜる。** 文字を打つほどポップコーンが弾け、設備が勝手に焼き、
> 数兆粒に達したら店ごと売って伝説の塩を手に入れる ―― 宇宙規模のポップコーン経営シミュ。

- **コア体験**: ターンッ！とキーを叩くと画面いっぱいにポップコーンが弾ける爽快感。
- **対象プレイヤー**: タイピング練習したい層 ＋ クリッカー／放置ゲーム好き。
- **プラットフォーム（想定）**: Web（PC キーボード前提）。後にモバイルはソフトキーボード or タップ代替を検討。

---

## 1. コアゲームループ

```
①お題の文字を打つ → ②ポップコーン獲得（コンボ補正あり）
        ↑                          ↓
④設備購入 / 品種研究 ← ③ポップコーンを通貨として消費
        ↓
（充分インフレしたら）⑤転生でリセット＋アーティファクト獲得 → ①へ
```

- **短期ループ（秒）**: 打鍵 → 弾ける → コンボが伸びる。
- **中期ループ（分〜時間）**: 品種アンロック・設備購入でレート上昇。
- **長期ループ（日〜）**: 転生でアーティファクトを積み、再スタートが加速。

---

## 2. 通貨と単位

| 通貨 | 入手 | 用途 |
|---|---|---|
| **ポップコーン（粒 / kernel）** | 打鍵・設備の自動生産 | 品種研究、設備購入 |
| **塩（Salt）※転生通貨** | 転生時に総生産量に応じて獲得 | 永続アップグレード、アーティファクト |

- 数字は天文学的にインフレするため、内部は `BigInt` もしくは仮数部＋指数（`1.23e45`）で保持。
- 表示は K / M / B / T → aa, ab, ac... の **短縮表記**を用意（クリッカー定番）。

## 3. アップグレード①：タイピング力（自力）

プレイヤー自身の打鍵で得る量を強化する系統。

### 3-1. 高級品種のアンロック（1打鍵あたりの火力）

| 品種 | 1文字あたり | アンロック目安コスト |
|---|---:|---:|
| 普通のコーン | 1 粒 | 初期 |
| キャラメルコーン | 5 粒 | 1,000 |
| トリュフ塩コーン | 50 粒 | 50,000 |
| 純金のコーン | 1,000 粒 | 5,000,000 |
| （以降、隠し品種で更にインフレ） | … | … |

- 品種は **研究ツリー**として進め、購入すると基礎レートが置き換わる（加算でなく乗算的に伸びる）。

### 3-2. コンボ・打鍵スキル（気持ちよさ強化）

| スキル | 効果 | 備考 |
|---|---|---|
| ノーミス・コンボ | 連続 10 文字ノーミスで獲得量 ×2（段階で ×4, ×8…） | ミスでリセット |
| ターンッ！破裂 | Enter 確定時にボーナス破裂（確定 or 一定確率で大爆発） | タイピングゲーム的快感 |
| 速度ボーナス | WPM（分間打鍵数）が高いほど倍率上昇 | リアルタイム計測 |
| パーフェクト・フィニッシュ | 1 文をノーミス完走でまとめ弾け | お題文ごとの達成感 |

> **設計メモ**: コンボ倍率は「上限なしだが伸びにくい」曲線にして、上手い人ほど自力で稼げる余地を残す。
> 放置勢とのバランスは転生通貨側で吸収する。

## 4. アップグレード②：設備投資（自動化・放置）

打っていない間も（打っている間も追加で）自動生産する設備。秒間生産量（CPS: kernels/sec）で管理。

### 序盤（ほのぼの）
| 設備 | 目安 CPS |
|---|---:|
| おばあちゃんのフライパン | 1 |
| 焚き火 | 8 |
| 電子レンジ | 47 |

### 中盤（本格化）
| 設備 | 目安 CPS |
|---|---:|
| 映画館の業務用マシン | 1,400 |
| 屋台のポン菓子機 | 7,800 |
| 巨大ポップコーン工場 | 44,000 |

### 終盤（カオス）
| 設備 | 目安 CPS |
|---|---:|
| 活火山にコーンを投下 | 260,000 |
| 地球の地熱を全振り | 1,600,000 |
| 太陽光収束ダイソン球 | 10,000,000+ |

- 各設備は **複数台購入可**、台数ごとにコスト上昇（係数 ×1.15 が定番）。
- 設備ごとの **個別アップグレード**（「フライパンを鉄製に → 出力 ×2」等）でフレーバーを足す。
- **オフライン生産**: 離席中も一定割合（例: 通常の 50%、上限○時間）で生産。復帰時に「焼けてたよ」演出。

## 5. アップグレード③：転生（プレステージ）

クリッカーの中毒性の核。「強くてニューゲーム」。

- **発動条件**: 累計／所持が天文学的（例: 数兆粒）に到達で「お店を売却」可能。
- **リセット対象**: 所持ポップコーン、品種、設備（＝ほぼ全部）。
- **引き継ぐもの**: **塩（転生通貨）**（＋将来的にアーティファクト）。
- 獲得塩量 = f(その周回の総生産量)。平方根カーブ等で「伸びるほど次が楽」に。

### 実装方針：A → B → C の段階拡張（決定）
最初から全部作らず、転生で強くなる手触りを最優先に段階導入する。

- **フェーズA（まずこれで実装）**: 塩＝そのまま倍率。
  - 塩を**持っているだけ**で全獲得量に倍率（例: 塩1個 = +10%）。買う・選ぶ操作ゼロ。
- **フェーズB（次に拡張）**: 塩で買う永続アップグレード（ショップ＝リスト UI）。
  - 例: 「全獲得 ×2」「設備 CPS 強化」「初期資金ボーナス」「コンボ倍率アップ」。買ったら永続。
- **フェーズC（余裕が出たら飾りとして追加）**: 絵つきアーティファクトのコレクション。
  - 例: 伝説の魔法の塩（全獲得 ×10）、黄金のフライパン（設備 CPS 大幅アップ）。画像・管理コストが高いので後回し。

## 6. 演出・気持ちよさ（重要）

- 打鍵ごとに粒が物理で弾け飛ぶ。コンボでエフェクト・SE が派手に。
- Enter 確定の「ターンッ！」に専用の決め演出。
- 画面が徐々にポップコーンで埋まり、転生直前は画面が黄色で溢れる。
- 数字インフレ自体をギャグとして見せる（「太陽を消費しています」等のフレーバーテキスト）。

### 6-1. 「ポンッ！」弾けエフェクトはコードで表現（決定）
- 専用の「弾け画像」は不要。**手持ちの品種 PNG をそのまま粒スプライト**として使い、CSS/Canvas でアニメ。
- 打鍵 → 粒が拡大＋バウンド → 回転しながら散ってフェード。同時に `ポンッ！.mp3`（連打時はピッチ/音量を微ランダム）。
- コンボ時は多めに弾く＋発光、Enter 確定で大きく破裂。
- ミス／焼きすぎ時は **真っ黒こげの粒**を混ぜるフィードバックも可能。

### 6-2. 表示数の上限とスコアの分離（決定）★重要
1000 粒を実際に描画すると重い／バグるため、**見た目（粒）と数字（スコア）を完全に分離**する。

- **画面に同時表示する粒は上限制**（例: 50〜150 個）。**オブジェクトプールで使い回す**ので、何粒稼ごうが描画コストは一定。
- 所持ポップコーンは内部でいくらでも増える（指数表現＋短縮表記）。**でかい数字＋増加アニメ＋効果音**で実感を出す。
- 見せ方は2系統を併用:
  - **飛び散り型**: 打つたびに粒が舞って消える（上限内で循環）。軽快。
  - **山盛り型**: 画面下に積もり、満タンで見た目は頭打ち・数字は伸び続ける。「埋め尽くし」演出。満タン＝転生の合図にもなり導線化。

## 8. 想定する技術メモ ※ドラフト段階

- 大きな数: `BigInt` か仮数＋指数表現＋短縮フォーマッタ。
- セーブ: localStorage（オフライン生産のため最終時刻も保存）。
- ゲームループ: `requestAnimationFrame` + 経過時間ベースで CPS 加算。
- 入力判定: **ソルジャータイピングの `typing-engine.js` を踏襲**（IME回避の `keydown` 直取り／ローマ字の複数綴り許容／促音・拗音対応）。WPM・コンボはこの上で集計。
- 描画: 粒はオブジェクトプール（§6-2）。画像は表示サイズに圧縮・リサイズして読み込み軽量化。
