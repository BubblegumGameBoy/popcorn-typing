# 🍿 ポップコーン・タイピング（スコアアタック版）

60秒のタイピングで、どれだけポップコーンを焼けるかを競うゲーム。
稼いだポップコーンは「貯金」に貯まり、ショップで **品種** と **アーティファクト**
（永久強化）を購入 → 次の挑戦が強くなる。やるほどスコアが伸びる！

## 遊び方
1. `index.html` をブラウザで開く（PCキーボード推奨）。
2. **スタート** → 3カウント後、60秒のタイムアタック。
   - お題のローマ字を打つとポップコーンが**花火のように破裂**して増える。
   - ヘボン式/訓令式どちらでもOK（し=shi/si）。長音「ー」は `-` でも母音でも可（バター=`bata-`/`bataa`）。
   - 連続ノーミスで**コンボ倍率**（×2〜×10）。打鍵ごとに「+N」が浮かぶ。
   - むずかしいお題は **Enter** でスキップ可。
3. **リザルト**：今回スコア・WPM・命中率・最大コンボ・順位（自己ベスト/世界）。
4. **ショップ**：貯金で永久強化を購入。
   - 🌽 品種：1打鍵の基礎を強化（普通→キャラメル→トリュフ→純金）。
   - ✨ アーティファクト：全獲得×倍率／基礎+／コンボ強化／**制限時間+秒** など。
5. もう一回！ 強くなった状態で再挑戦。

## ランキング
- **自己ベスト**：端末内（localStorage）に自動保存。すぐ動く。
- **世界ランキング**：Firebase Realtime DB を使うと有効化できる（任意）。
  1. Firebase で Realtime Database を作成（無料枠でOK）。
  2. ルールで `/scores` の読み書きを許可。
  3. `index.html` の先頭で URL を設定：
     ```html
     <script>window.LEADERBOARD_URL = 'https://xxxx-default-rtdb.firebaseio.com';</script>
     ```
  これだけで世界ランキングがONになります（SDK不要・REST API）。

## ローカルで動かす
```bash
python3 -m http.server 8000   # → http://localhost:8000/
```

## 構成
```
index.html            画面（タイトル/ショップ/プレイ/リザルト）
styles.css            スタイル
src/
  config.js           ★バランス（品種・アーティファクト・コンボ・秒数）全部ここ
  game.js             メタ進行＋1戦のロジック（描画なし）
  data/words.js       お題（テーマ語＋流行語、engine検証済み）
  typing-engine.js    ローマ字判定（IME回避・複数綴り・長音ー対応）
  effects.js          花火パーティクル＆サウンド
  leaderboard.js      ランキング（端末内＋世界）
  ui.js / main.js     画面描画 / 統合・状態遷移
assets/
  images/  元画像 ／ web/ 表示用に軽量化 ／ audio/ 音
```

## バランス調整
`src/config.js` に集約。秒数・品種コスト・アーティファクト効果/コスト・コンボ倍率を
ここだけで調整できます。
