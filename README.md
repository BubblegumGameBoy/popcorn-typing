# 🍿 ポップコーン・タイピング

タイピング × クリッカー（放置）ゲーム。
文字を打つほどポップコーンが弾け、設備が自動で焼き、数兆粒に達したら
お店を売って「伝説の塩」を手に入れる ―― 宇宙規模のポップコーン経営シミュ。

## 遊び方
1. `index.html` をブラウザで開く（PCキーボード推奨）。
2. お題のローマ字を打つと、ポップコーンが弾けて増える。
   - ヘボン式／訓令式どちらでもOK（し = shi / si）。
   - 連続ノーミスで **コンボ倍率**（×2〜×10）。
   - ワードを打ち切ると「ターンッ！」と大破裂ボーナス。
   - むずかしいお題は **Enter** で次へスキップ可。
3. 貯めた粒で **品種**（1打鍵の火力）と **設備**（自動生産）を強化。
4. 充分に焼いたら **転生**：すべてを失う代わりに「塩」を獲得し、
   全生産が永続で強くなる（強くてニューゲーム）。

## ローカルで動かす
ただ開くだけでも動きますが、音声をブラウザの制限なく鳴らすなら簡易サーバー推奨:

```bash
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## 構成
```
index.html            画面・スクリプト読み込み
styles.css            スタイル（遊園地×ポップコーンの世界観）
src/
  assets.js           画像・音声のパス管理（軽量版 assets/web/ を参照）
  format.js           大きな数の短縮表記（K/M/B/T…）
  config.js           ★ゲームバランス（品種・設備・コンボ・転生）全部ここ
  data/words.js       お題（テーマ語＋流行語、104問・engine検証済み）
  typing-engine.js    ローマ字判定エンジン（IME回避・複数綴り許容）
  effects.js          パーティクル（粒の弾け）＆サウンド
  game.js             状態・経済ロジック・セーブ／転生（描画なし）
  ui.js               DOM描画
  main.js             統合・入力・ゲームループ
assets/
  images/             元画像（高解像度・保管用）
  web/                表示用に軽量化した画像（ゲームはこちらを使用）
  audio/{bgm,se}/     BGM・効果音
docs/GAME_DESIGN.md   企画ドラフト
```

## バランス調整
数値は `src/config.js` に集約。品種コスト・設備CPS・コンボ倍率・転生カーブを
ここだけで調整できます。

## クレジット
- 入力エンジンは別プロジェクト「ソルジャータイピング」の方式を踏襲。
- 画像・音声はプロジェクト用に用意したオリジナル素材。
